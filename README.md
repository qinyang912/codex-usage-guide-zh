## Plus、Pro、Credits 与 API 的区别

- **Plus / Pro**：订阅套餐，包含用量与功能取决于当前套餐。
- **ChatGPT Credits**：给账号支持的功能补充用量，不会自动升级会员；能否购买以账号内入口为准。
- **API 余额**：用于 API Key 路径，按开发者平台账单结算，不与 ChatGPT 套餐余额混用。

[官方 Codex 定价与用量说明](https://learn.chatgpt.com/docs/pricing)给出了估算范围，不能把它换算成每个账号保证可发送的固定条数。查看剩余额度，应进入[官方 Usage Dashboard](https://chatgpt.com/codex/settings/usage)。

## 充值前检查清单

先确认套餐、周期、账号归属、最终金额、所需资料和退款条件。付款前已存在订阅时，应先确认原渠道是否还会扣费；已扣款但结果不明时不要重复购买。
